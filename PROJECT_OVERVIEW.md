# AQI Capstone Project

## Project Overview

AQI Capstone Project is a Python Flask application for analyzing and presenting Air Quality Index (AQI) information. It combines prepared datasets, exploratory notebooks, backend application logic, templates, and static assets to provide a user-facing air-quality analysis experience.

## Main Components

- `app.py` — Flask application entry point.
- `dataset/` — Data used for AQI analysis.
- `notebook/` — Data exploration, preprocessing, and modeling work.
- `templates/` — HTML pages for the web interface.
- `static/` — CSS, JavaScript, and other frontend assets.

## Purpose

The project demonstrates how data science and web development can be combined to transform air-quality data into accessible insights. It is intended as an educational capstone project covering data preparation, analysis, visualization, and Flask-based deployment.
